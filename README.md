# Análise de Veículos - Web App Streamlit

Este aplicativo web interativo foi construído utilizando Streamlit e Plotly Express para realizar a análise exploratória de dados de um conjunto de anúncios de vendas de carros.

## Funcionalidades
- Exibição de cabeçalho informativo.
- Filtro interativo por caixa de seleção (*checkbox*) para geração de histograma do odômetro.
- Filtro interativo por caixa de seleção (*checkbox*) para geração de gráfico de dispersão (Preço vs. Odômetro).
